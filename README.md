# FashionIQ — Competitive Fashion Intelligence Dashboard

> A data-driven fashion intelligence dashboard for comparing brands, pricing, assortment, discounts, and competitive positioning across the fashion market.

**Live Demo:** https://nuprr.github.io/fashion-brand-insights/  
**Repository:** https://github.com/NUPRr/fashion-brand-insights

---

## Overview

**FashionIQ** is a competitive fashion intelligence dashboard designed to turn fashion-market data into clear, actionable insights.

The dashboard compares **Zara, H&M, and AZORTE** across key areas such as:

- Product pricing
- Category assortment
- Discounting
- Brand positioning
- Competitive trends
- Product-level intelligence

The project focuses on presenting complex competitive data through a clean, interactive dashboard experience.

---

## Key Features

### Competitive Brand Analysis
Compare major fashion brands across pricing, positioning, and category performance.

### Category Intelligence
Explore category-level assortment across:

- Denim
- Dresses
- Tops
- Ethnic Wear
- Footwear
- Kids
- Accessories
- Outerwear

### Pricing Analysis
Compare average and category-level prices across competing brands.

### Discount Intelligence
Identify discount patterns and compare promotional intensity between brands.

### Product Intelligence
Filter products by:

- Brand
- Category
- Discount status

View product-level information including price, discount, collection, and observation date.

### Interactive Dashboard
The dashboard includes interactive charts, filters, comparison cards, and visual insights designed for quick decision-making.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/NUPRr/fashion-brand-insights.git
```

### 2. Navigate to the project

```bash
cd fashion-brand-insights
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available on the local Vite development server.

### 5. Create a production build

```bash
npm run build
```

## Data Note

The product-level dataset used in this project is **illustrative** and is intended to demonstrate competitive fashion intelligence, dashboard design, filtering, and data visualization workflows.

The dashboard should not be interpreted as a live feed of current retailer inventory or verified real-time market pricing.

---

## Design Approach

FashionIQ combines a **fashion-focused visual language** with a structured business intelligence interface.

The design emphasizes:

- Clear information hierarchy
- Editorial-style visual presentation
- Data readability
- Minimal visual clutter
- Interactive exploration
- Responsive layouts

The goal is to make competitive fashion data easier to understand and act upon.
